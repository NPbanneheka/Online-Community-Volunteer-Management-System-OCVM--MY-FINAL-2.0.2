OCVMS user account management update

Added:
1. Admin user deletion
   - Admin can delete Organizer and Volunteer accounts from Profile > User Management.
   - Admin accounts and the currently logged-in admin account are protected from deletion.
   - Related profile data, events, registrations, community posts, comments, support requests, notifications, and ratings are removed safely.

2. Change password feature
   - Logged-in users can change their password from the navbar or profile page.
   - Current password is required.
   - User remains signed in after successful password change.

3. Verification status fix
   - Admin verification updates all profile rows linked to the same Identity user.
   - My Profile now reads the primary verified/latest profile, so the badge changes from Pending to Verified correctly.

4. Runtime schema patch improvement
   - Event registration date columns are created using separate safe SQL batches.
   - This prevents Invalid column name errors on restored group databases.
